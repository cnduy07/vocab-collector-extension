Vocabulary Collector Settings

Google Translate is used by default and needs no setup — it is the same engine as translate.google.com. The built-in IT glossary overrides it for technical terms. Add a DeepL API key if you prefer DeepL, and a Google Apps Script Web App URL to sync saves to a Sheet.

Translation

If the chosen engine fails, the next one is tried automatically so a lookup rarely comes back empty. Google Translate also returns the other senses of a word, shown under the meaning.

Technical terms are translated from a curated glossary instead of a general engine, so commit, thread, and socket get their software meaning. For words whose everyday meaning differs, both are shown.

Adds a collapsible “Nghĩa trong câu” line to the lookup card, which disambiguates words that carry several meanings.

Engine credentials

Use https://api-free.deepl.com/v2/translate for a free DeepL account, or https://api.deepl.com/v2/translate for a paid account.

Google Sheets Sync

Use a long random secret and keep the same value in Apps Script and this setting. If sync is off or fails, the word is still saved locally. Unsynced records are marked in the popup.
